# ТНЭ чат — помощник по странице для Firefox

Версия: `0.7.0-firefox`.

Расширение открывает боковую панель, извлекает контекст текущей страницы и отправляет вопрос пользователя в корпоративный endpoint:

```text
https://llm-prod.tne.tn.corp:13600/api/v1/chat/generate
```

## Что умеет

- забирает основной текст страницы;
- не включает в контекст собственную панель расширения;
- читает видимые модальные окна, формы, поля, кнопки и таблицы;
- обновляет контекст при смене `document.location` в SPA;
- ограничивает общий контекст 15000 символами;
- показывает предпросмотр извлечённого текста;
- позволяет вручную обновить контекст;
- позволяет очистить переписку;
- использует стиль и палитру ТНЭ чата.

## Установка для теста

1. Распаковать архив.
2. Открыть в Firefox:

```text
about:debugging#/runtime/this-firefox
```

3. Нажать **Загрузить временное дополнение**.
4. Выбрать файл `manifest.json` из распакованной папки.

## Настройки

Откройте настройки расширения и укажите токен.

По умолчанию:

```text
Auth header: Authorization
Prefix: Bearer 
```

Если backend ждёт ключ в `X-Proxy-Key`, укажите:

```text
Auth header: X-Proxy-Key
Prefix: 
```

## Важно

Для промышленного варианта лучше не хранить токен в расширении. Правильная схема:

```text
Firefox Extension → corporate backend/proxy → LLM endpoint
```


## Изменения v0.7.0-firefox

- Добавлен безопасный `MutationObserver`: контекст автообновляется после дозагрузки DOM с debounce/throttle, без постоянного пересчёта на каждую мутацию.
- Перед каждым запросом контекст страницы принудительно пересобирается заново.
- Добавлено чтение динамически появившихся модальных окон, форм, интерактивных элементов и contenteditable-блоков.
- Добавлен компактный переключатель размера текста 12/13/14 px.
- Кнопка очистки заменена на иконку ластика, иконки сверху увеличены.


## Версия 0.7.0

- Новый логотип ТНЭ чат · Браузер во всех местах: иконка расширения, панель, настройки.
- Панель открывается справа с layout shift: страница получает правый отступ и контент не перекрывается панелью.
- Если сайт построен на фиксированных контейнерах/Canvas/нестандартной вёрстке, часть элементов может всё равно оставаться под панелью — это ограничение content-script подхода.
- Расширение собрано как ZIP и неподписанный XPI. Для постоянной установки в обычном Firefox требуется подпись Mozilla или корпоративная политика установки.
